# TalkyTots

> **Mini Practice Project: Real-Time Chat with Socket.IO**

**TalkyTots** is a hands-on, open source project for learning how to build a real-time chat system using Socket.IO, React, Express, and MongoDB. If you want to understand the basics of sockets, live messaging, and full-stack web apps, this is the perfect playground!

---

## 🚀 What You'll Learn
- How to use Socket.IO for real-time communication
- Building a chat UI with React & TailwindCSS
- Managing rooms, users, and messages with Express & MongoDB
- Authentication basics (signup/login)
- Structuring a full-stack project

## 🗂️ Project Structure
```
TalkyTots/
  client/   # React + Vite frontend
  server/   # Express + Socket.IO backend
```

## 🛠️ Getting Started
1. **Clone the repo:**
   ```powershell
   git clone https://github.com/luqmanbooso/TalkyTots.git
   cd TalkyTots
   ```
2. **Install dependencies:**
   ```powershell
   cd client; npm install
   cd ../server; npm install
   ```
3. **Configure environment:**
   - Add a `.env` file in `server/` (see `server/index.js` for required variables)
4. **Run the backend:**
   ```powershell
   npm start
   ```
5. **Run the frontend:**
   ```powershell
   npm run dev
   ```
6. **Open your browser:**
   - Visit the local URL shown in the terminal and start chatting!
